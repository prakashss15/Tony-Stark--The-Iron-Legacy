ABOUT THIS WEBSITE

Project Overview & Features

A Tribute to Iron Man

This website is a premium, cinematic portfolio built as a tribute to Tony Stark. It is designed to mimic the futuristic Stark Industries HUD, providing an immersive, highly interactive experience that explores his legacy across the Marvel Cinematic Universe.

The project features a custom-built Bright / Dark Theme System, allowing users to toggle between the classic dark cyber-aesthetic and a clean, modern bright interface seamlessly.

Key Features Included:

  • Interactive Suits Gallery: Browse through an immersive gallery of Iron Man armors with hover animations and detailed specifications.
  • Dynamic Theme Toggle: A persistent theme switcher seamlessly transitions the entire site between Dark and Bright modes using CSS variables and LocalStorage.
  • Cinematic Animations: Powered by GSAP (GreenSock), featuring scroll-triggered reveals, typewriter effects, and parallax scrolling.
  • Responsive Design: Fully optimized for desktop, tablet, and mobile devices with a custom mobile navigation menu.
  • Interactive Timeline: A visual timeline charting Tony Stark's major milestones from 1970 to 2023.
